# FM1 Bass Station RC1

RC1 changes the FM1 control workflow and simplifies the on-device UI.

- SELECT = Filter Cutoff outside the SEL preset browser.
- ALGO = Filter Resonance outside the SEL preset browser.
- SELECT/PRESET browse patches and ALGO selects Factory/User bank inside the SEL page.
- Normal synth pages use clean four-control 2x2 layouts with no lower footer.
- 303 Generate/Mutate use the same layout; editor grids keep their specialized views without the old footer.
- Splash hold is doubled to 800 ms and marked RC1.
- TEST21 USER bank, sequencer, declick and USB-C web-editor features are retained.

Use `FM1-BassStation-RC1.fwsc` for the normal update. No generic M-Flasher is included because a full-flash image cannot preserve per-device USER-bank data.
