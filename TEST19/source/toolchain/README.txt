TEST19 does not republish the third-party Jieli compiler archive in the compact
GitHub source tree. To build target firmware, either:

1. set JIELI_TOOLCHAIN to an extracted jieli-linux-toolchains-20260730.1 folder, or
2. put jieli-linux-toolchains-20260730.1.tar.xz in this directory.

`bash build.sh --host` does not need the target compiler.
