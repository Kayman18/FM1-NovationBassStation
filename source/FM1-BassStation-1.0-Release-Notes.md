# FM1 Bass Station 1.0

- Four-control synth and sequencer pages use shaded knobs with live position markers. Home has a compact knob layout above the preset name.
- Cutoff is displayed in hertz on Home, Filter, and the temporary filter overlay. Presets still begin at about 224 Hz.
- External sequencers can send **CC74** for Cutoff and **CC71** for Resonance over USB or TRS MIDI. The Bass Station plug-in mappings **CC105** and **CC106** also work.

The FM-1 updater identifies this release as `FM-1_20010003` (internal version 1.0.3), which follows RC3.

Use the FWSC for normal updates and to preserve the USER bank. The clean-install M-Flasher writes the full flash, including USER data and settings.
