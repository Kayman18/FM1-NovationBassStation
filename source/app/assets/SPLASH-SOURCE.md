# Bass Station splash source note

The TEST18 FM1 splash was created from the user-approved Bass Station splash
composition, itself based on the Novation Bass Station II product image at:

https://cdn11.bigcommerce.com/s-itgb7ssiy1/images/stencil/2560w/image-manager/bass-station-ii-top-2400-2400.png?t=1751460739

`bass_station_splash_240.png` is the 240×240 firmware preview. The build embeds
its 16-colour packed representation from `../splash_bassstation.h`.

Novation and Bass Station names/trade dress remain the property of their
respective owner; this file records source/provenance for the port project.
