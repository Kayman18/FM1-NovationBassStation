FM1 Bass Station TEST20 USER-bank safety

Use FM1-BassStation-TEST20.fwsc for the normal TEST20 update.
The FWSC loader writes only the application area and leaves the Bass Station
USER-bank store sectors untouched.

A generic full 1 MiB M-Flasher is intentionally not included in TEST20.
Such an image is based on a clean reference backup and cannot preserve the
unique USER-bank contents already stored on a particular FM1.

If TEST19 was installed using the generic M-Flasher and the USER bank became
empty immediately afterward, the saved sectors may have been replaced by the
reference image. Recovery then requires a previous FM1 flash backup or an
exported Bass Station USER-bank/SysEx copy; firmware cannot reconstruct patches
that are no longer present in flash.
